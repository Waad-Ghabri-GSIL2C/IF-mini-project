# IF Mini Project — Interactive Gantt Chart

A tiny interactive Gantt chart, built from scratch with plain HTML/CSS/JS, mapping out my own mini project internship timeline.

## What it does
- Displays each step as a colored bar
- Click a bar to see details: description, dates, % completion, delay
- Built to practice DOM manipulation and event handling

## What I learned
- How HTML, CSS, and JS connect
- Looping over data to generate elements dynamically
- Event listeners and variable scope
- Basic git/GitHub workflow
