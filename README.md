# Interactive Gantt Chart TRIAL

A small interactive Gantt chart built from scratch with HTML, CSS, and JavaScript, visualizing the timeline of my IF mini project internship steps.

Built as a hands-on learning project to practice core frontend fundamentals — no frameworks, no libraries, just the basics done properly.

## Features

- Dynamic rendering of tasks from a JavaScript data array
- Color-coded bars by task category
- Hover tooltips showing task details
- Click-to-select interaction with a details panel (description, dates, % completion, delay)
- Inline progress indicator per task

## Tech stack

- HTML5
- CSS3 (Flexbox, relative/absolute positioning)
- Vanilla JavaScript (DOM manipulation, event listeners)

## What I learned

- Structuring and looping over data (`array of objects`) to generate UI dynamically
- DOM manipulation: `createElement`, `appendChild`, `textContent` vs `innerHTML`
- Event-driven interactivity with `addEventListener`
- CSS positioning patterns (`relative` + `absolute`) for nested elements
- Debugging real issues: variable scope, browser caching, and Git remote configuration errors

## How to run it

No build step required — it's plain HTML/CSS/JS.

2. Open `index.html` in any browser
